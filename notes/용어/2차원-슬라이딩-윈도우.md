## 한 줄 정의

2차원 배열(격자) 위에서 고정 크기의 `k×k` 창을 한 칸씩 옮기며, 이전 창의 계산 결과를 재활용해 각 창의 합·최댓값 등을 빠르게 구하는 기법.

## 자세히

1차원 슬라이딩 윈도우는 창이 오른쪽으로 한 칸 이동할 때 "빠지는 원소 하나를 빼고, 들어오는 원소 하나를 더하는" 식으로 매번 전체를 다시 계산하지 않는 기법이다. 2차원은 이걸 격자에 확장한 것으로, 창이 오른쪽으로 한 칸 이동하면 **왼쪽 열 하나가 빠지고 오른쪽 열 하나가 들어온다**. 즉 원소 단위가 아니라 **열(또는 행) 단위**로 빼고 더한다.

나이브하게 모든 위치에서 `k×k` 창을 전부 다시 합산하면 `O(n·m·k²)`가 걸린다. 슬라이딩 방식은 창 이동마다 열 하나(원소 `k`개)만 갱신하므로 `O(n·m·k)`로 줄어든다. 여기서 더 나아가 **행 방향으로 먼저 1차원 슬라이딩을 해서 "각 행의 구간 합"을 만들어 두고, 그 결과에 다시 세로 방향 슬라이딩을 적용**하면 창 이동이 `O(1)`이 되어 전체 `O(n·m)`까지 내려간다.

합(sum)만 필요하다면 실전에서는 **2차원 누적합(prefix sum)** 을 쓰는 경우가 더 많다. 누적합 테이블을 `O(n·m)`에 만들어 두면 임의 위치의 `k×k` 합을 공식 한 줄로 `O(1)`에 꺼낼 수 있어서 코드가 더 단순하다. 반면 **최댓값·최솟값**처럼 "빠진 원소를 되돌리기 어려운" 연산은 누적합으로 안 되므로, 행마다 모노톤 덱(monotonic deque)으로 1차원 슬라이딩 최댓값을 구한 뒤 열 방향으로 한 번 더 적용하는 2단계 슬라이딩 윈도우가 표준 풀이다.

정리하면: **합 → 2차원 누적합이 간편, 최대/최소 → 행·열 2단계 슬라이딩 윈도우(모노톤 덱)**. "2차원 문제는 1차원 기법을 행 방향으로 한 번, 그 결과에 열 방향으로 한 번 적용한다"는 게 핵심 발상이다.

## 예시

`n×m` 격자에서 `k×k` 창의 합의 최댓값 구하기 (행→열 2단계 슬라이딩, `O(n·m)`):

```cpp
long long maxKxKSum(const vector<vector<long long>>& grid, int k) {
    int n = grid.size(), m = grid[0].size();

    // 1단계: 각 행에서 가로 길이 k 구간 합 (1차원 슬라이딩)
    vector<vector<long long>> rowSums(n, vector<long long>(m - k + 1));
    for (int i = 0; i < n; i++) {
        long long acc = 0;
        for (int j = 0; j < k; j++) acc += grid[i][j];
        rowSums[i][0] = acc;
        for (int j = k; j < m; j++) {
            acc += grid[i][j] - grid[i][j - k];  // 들어오는 값 더하고 빠지는 값 빼기
            rowSums[i][j - k + 1] = acc;
        }
    }

    // 2단계: 그 결과를 세로 방향으로 다시 슬라이딩
    long long best = LLONG_MIN;
    for (int j = 0; j <= m - k; j++) {
        long long acc = 0;
        for (int i = 0; i < k; i++) acc += rowSums[i][j];
        best = max(best, acc);
        for (int i = k; i < n; i++) {
            acc += rowSums[i][j] - rowSums[i - k][j];
            best = max(best, acc);
        }
    }
    return best;
}
```

같은 문제를 2차원 누적합으로 풀면, `P`를 누적합 테이블이라 할 때 `(r, c)`에서 시작하는 `k×k` 합은:

```text
S = P[r+k][c+k] - P[r][c+k] - P[r+k][c] + P[r][c]
```
