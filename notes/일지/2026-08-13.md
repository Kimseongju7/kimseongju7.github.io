**스택 PR 은 위에서부터 접어 내려야 한다**

- ✨ 아래 PR 을 base 브랜치로 먼저 머지하면, 그 위에 얹힌 PR 은 **이미 소진된 base** 로 들어가 최종 브랜치까지 못 올라온다. MERGED 배지는 달리지만 코드는 develop 에 없고, `Closes` 키워드도 발동하지 않아 이슈가 열린 채 남는다. 스택은 위(#187)를 base 브랜치에 먼저 접어 넣고 그다음 아래(#184)를 develop 으로 올려야 한다. 꼬였을 땐 리베이스해서 재상신하는 게 제일 깔끔했다.

**JPA assigned-id 엔티티에서 `save()` 는 merge 경로를 탄다**

- ✨ UUID 를 앱에서 직접 할당하는 엔티티는 `save()` 가 persist 가 아니라 **merge** 로 가고, `@PrePersist` 는 **머지된 사본에서만** 실행된다. 그래서 `saveAndFlush()` 반환값을 버리고 원본 인스턴스를 응답으로 직렬화하면 `createdAt` 같은 콜백 채움 필드가 null 로 나간다. 반드시 반환된 관리 엔티티를 써야 하고, 이 패턴은 한 군데서 발견되면 코드베이스 전수 조사를 해야 한다 — 실제로 전수 조사에서 공유 링크 발급 응답의 같은 결함이 하나 더 나왔다.

**토큰 형식을 구분자 개수로 판별하면 안 된다**

- ✨ "점으로 쪼개서 3조각이면 JWT" 같은 휴리스틱은 페이로드에 우연히 구분자가 들어가면 무너진다. JSON 클레임 안에 이메일이 두 개 있으면 점이 정확히 2개가 되어 JWT 로 오판되고 base64 디코드에서 크래시한다. **접두 문자로 형식을 확정**하고(`{` 로 시작하면 JSON), 파싱 실패는 500 이 아니라 의미 있는 4xx 로 떨어뜨리는 게 맞다.

**앵커 모델: `anchor` / `currentAnchor` / `link`·`noChange` 는 서로 다른 축**

- ✨ `anchor` 는 피드백을 단 순간의 좌표+텍스트 스냅샷으로 **불변 저장값**이고, `currentAnchor` 는 새 버전에서 같은 대목을 재탐색해 찾은 위치로 **응답 파생값**(못 찾으면 고아). `link`·`noChange` 는 "이 피드백이 변경에 반영됐는가"라는 완전히 별개의 축이다. 이 셋을 섞으면 버그가 난다 — noChange 라고 스크롤을 막았던 게 정확히 그 오판이었고(문장이 살아 있으면 관련 변경이 없어도 위치는 존재한다), 갓 만든 피드백에 currentAnchor 가 null 인 것도 데이터 유실이 아니라 **아는 값을 안 내보내는 응답 조립 누락**이었다.

**컨테이너에 스토리지 볼륨을 안 붙이면 이미지 교체 때 파일이 사라진다**

- ✨ 검수 중 pdf·hwp 문서가 갑자기 "불러올 수 없어 추출 텍스트를 표시" 폴백으로 떨어졌는데, 코드 회귀가 아니라 **최신 develop 으로 컨테이너를 재빌드·교체하면서 컨테이너 내부 경로에 있던 업로드 파일이 통째로 날아간 것**이었다. FE 폴백 동작 자체는 설계대로 작동한 거라 오히려 폴백이 잘 짜였다는 증거였지만, 검수 환경에서는 이런 환경 요인을 결함과 먼저 갈라내야 헛수고를 안 한다.

**역할 경계를 넘은 수정은 되돌리고 이슈로 넘기는 게 낫다**

- ✨ 내가 찾은 BE 버그를 직접 고쳐 PR 에 실었다가 빼야 했는데, 결과적으로 **이슈로 넘긴 쪽이 더 나은 결과**를 냈다. 원인 분석과 검증 끝난 패치 코드를 이슈 본문에 그대로 담아 주면 담당자는 붙여넣기 수준으로 처리할 수 있고, 그 도메인을 아는 사람이 보면 내 패치보다 나은 처리(적절한 상태 코드, 같은 패턴 전수 조사)까지 얹힌다. 발견은 내 몫, 수정은 소관자 몫으로 나누는 게 맞다.

**토익 Part 5 — 어휘형 동사 선택은 목적어부터 본다**

- 동사의 의미에 따라 동사를 고르는 문제를 만나면 **제일 먼저 목적어를 본다.** 수동태라면 주어를 본다. 그 목적어와 각 보기의 호응 관계를 따지면 맞지 않는 보기가 지워지거나 바로 답이 나오기도 한다. 선택지가 좁혀지면 해석해서 확인한다.
- 그래도 답이 안 나오면 **구조를 분석한다.** 자동사인지 타동사인지, that 절을 취하는지, of·to·with 같은 전치사를 취하는지 — 전치사와의 호응 관계까지 봐야 한다.

**토익 Part 6 — 문제보다 지문의 의도를 먼저 잡는다**

- 어휘에 따른 동사 선택 문제는 **그 문장만 봐서는 알 수 없다.** 앞뒤 문장을 보고 문맥상 선택해야 한다. 단서는 보통 뒤에 나오고, 특히 첫 번째 문제는 거의 뒤에 단서가 있다.
- 그래서 Part 6 는 문제부터 풀려고 달려들기보다 **지문이 무엇을 말하려 하는지 먼저 파악**하는 게 낫다.
