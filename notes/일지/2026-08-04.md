**[설명회] 공기업 채용 트렌드**

- 지방공기업 통합채용은 1차 필기(시 주관) → 2차 서류 → 3차 면접 순이다. **서류는 90% 이상이 적부평가**이고 나머지 10%가 자소서·자격증 평가다.
- 직업공통능력 개편은 **2027년 본격 도입 예정이고 2026년은 현행 유지**라, 지금 따로 대비할 필요는 없다. 다만 **디지털 능력만은 주목**할 것 — NCS 사이트 교수자용 학습자료 수준이면 된다.
- 더 중요한 변화는 **기관 사업·정책 관련 질문이 크게 늘고 있다**는 점이다. 예전엔 시간 단축이 키였다면 이제는 정책·제도를 익숙하게 만들어 빨리 이해하고 정확하게 푸는 쪽이 핵심이다.
- 전공은 사무직이 **난이도는 낮아졌지만 범위가 넓어졌고** 지엽적 개념 위주다(회계는 계산보다 말문제). 금융 공기업만 2025년 대비 난이도가 올랐다. 기술직은 범위가 광범위하게 확대돼 **기사 수준 + 공무원 객관식 유형**이 됐다.
- 면접은 **경험보다 생각·가치관·기준**을 묻는 시나리오형이 확대됐다. AI 로 질문 대비가 쉬워진 탓에 꼬리 질문·상황 질문·정책 질문·토론·PT 가 늘었다. PT 는 지식 암기에서 **자료해석 형식으로 전환**됐으니, 평소 자료해석 문제를 버리지 않고 푸는 것이 그대로 면접 대비가 된다.

**[설명회] 목표 기관 선정 — 뭘 먼저 해야 하는지 알고 시작하기**

- 가장 가고 싶은 기관을 먼저 정하고 **스펙이 겹치는 곳으로 확장**한다. 대상은 적게는 5개, 많게는 10개.
- 채용을 가장 많이 하는 세 곳의 성격이 다르다. **한국전력**은 정량평가라 어학·자격증만 보고 스펙이 보편적이라 확장성이 좋으며 인턴이 필요 없다. **건강보험공단**은 종합평가라 자소서·자격증·교육·경력을 다 써야 해 서류가 어렵지만 전공을 하지 않아도 된다. **코레일(+서울교통공사)**은 수도권 근무가 장점, 교대근무가 단점이며 서류가 적부라 어학이 필요 없고 필기 가점이 세다 — 다만 철교안은 코레일 외에 쓸 곳이 없다.
- **필기는 100점을 맞는 시험이 아니다.** 보수적으로 잡아도 경쟁률이 10:1 이 안 되고 허수가 생각보다 많다.

**[설명회] NCS 필기 준비법 (김소원 선생님)**

- 시작은 3단계다. **기업 선정**(스펙·근무지역·연봉 고려해 5~10개) → **출제 유형 파악**(모듈/피듈/피셋, 단일 전공/통합 전공) → **현재 실력 체크**(녹색책 뒤를 시간 신경 쓰지 말고 풀어 60% 이상 맞고 해설이 이해되면 통합 기본서로, 아니면 기초서로).
- 시간 배분은 **초반 NCS, 후반 전공**. NCS 는 유형을 알고 풀이를 익히면 그다음은 훈련이라 보통 6개월이면 되지만, 전공은 끝이 없는 공부다.
- 교재는 **전부 최소 2회독**. ① 기본서는 회독할 때 다른 교재로 바꾸지 말 것(그래야 구멍이 메워진다) → ② 민경채 PSAT(7급)은 1회독에 정확도와 문항별 소요 시간을 측정해 **A·B·C군으로 나누고**, 2회독은 25문항 40분에 5문제쯤 버리며 푼 문제 정확도 80~90% 유지 → ③ 심화 교재 + 기본서 재회독 → ④ 모의고사는 학습용이 아니라 **오로지 점검용**(시간 관리·문제 선별력·정답률 유지 확인).
- **버리기도 연습해야 한다. 안 그러면 시험 때 못 버린다.** 시험이 끝났는데 문제도 남고 시간도 남았다면 평소에 훈련하지 않은 것이다.
- 직업기초능력 개편 내용: 자원관리 + 자기계발 → **자기관리능력으로 통합**, 문제해결에 의사결정 추가, **디지털능력 신설**(AI·책임의식 등 법률문제), 실제로 없어지는 건 **기술능력·조직이해능력**이다. 수리는 **어림산·단위환산과 통계**(확률·분포·경우의 수·조건부확률)가 강화되고 사칙연산·검산법은 빠진다. 난이도보다는 범위가 넓어지는 방향이다.
- 의사소통능력은 단독으로 준비하면 우선순위에서 밀리니 **KBS 한국어능력시험과 병행**하는 것이 효과적이다. 회사 보도자료도 그대로 출제되곤 하니 보는 게 도움이 된다.
- 정체기는 분명히 온다. 그때는 **객관적으로 원인을 찾아 다시 도전할 것 — 같은 것 반복은 하지 말 것.**

- ✨ 그래서 **애매한 결정(레이아웃 해석, 상태 전이 등)은 위임 프롬프트 단계에서 전부 확정해서 넘겨야 한다.** 행 번호·소유 파일 경계·용어표·완료 기준·검증 명령을 프롬프트에 박아 넣으면 결과가 흔들리지 않는다.
- ✨ 부수적으로 **`codex` CLI 를 백그라운드로 돌릴 때는 stdin 을 닫아야 한다**는 요령을 확보했다.

**"알 수 없음" 표시는 UI 버그가 아니라 API 계약의 공백**

- ✨ 게스트 화면에서 업로더가 "알 수 없음"으로 나오는 원인은 프론트가 아니었다. **버전 응답의 `uploadedBy` 가 사용자 ID 뿐**이고(`docs/api.md:801`), 멤버 이름은 그룹 멤버 목록 조회로 매핑하는데 **게스트 열람 계열에는 그 조회 자체가 없다**(`docs/api.md:1467~1473`). 즉 게스트 화면은 ID 를 이름으로 바꿀 수단이 구조적으로 없다.
- ✨ 해법은 이미 같은 레포 안에 있었다 — **피드백 응답이 작성자를 `{userId, name, isGuest}` 로 내장하는 패턴**을 버전 항목에도 적용하면 된다. 프론트에서 채울 수 없는 값은 화면에서 우회하지 말고 **계약 이슈로 올리는 게 맞다.**

**`.gitignore` 무시 규칙은 untracked 파일에만 작용한다**

- ✨ 이미 git 이 추적 중인 파일은 `.gitignore` 에 넣어도 계속 추적된다. 그래서 규칙을 추가할 때는 **`git check-ignore -v` 로 적중 확인 + `git ls-files` 로 추적분 무영향 확인**의 2단 점검이 필요하다.
- ✨ 이번엔 그 성질이 오히려 유리했다. 노트가 실제로 링크하는 `" 1"` 사본은 추적 상태로 남아 링크가 살아 있고, 중복 원본만 status 에서 사라졌다.

---

**`paths-ignore` 로 배포 트리거를 제어할 수 있다**

- ✨ `.github/workflows/pages-deploy.yml` 의 `paths-ignore` 에 `.gitignore` 가 들어 있어서, **그 파일만 바뀐 푸시는 GitHub Pages 배포를 돌리지 않는다.** 설정 파일 손보는 커밋이 매번 배포를 태우는 걸 막는 장치다.
