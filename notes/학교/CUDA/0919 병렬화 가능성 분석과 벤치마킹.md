## 1. 병렬화 가능성 분석
baseline : 비교의 기준이 되는 기본 구현이나 측정 결과
최적화 한 결과를 비교할 기준 값임.
단, 비교 시 입력 데이터, 정확성 기준, 측정 범위, 반복 횟수가 동일해야 함. 
즉, 변인 통제가 이루어져야 함
baseline은 이러한 비교 조건, 환경까지 포함한 개념임.

프로그램이 병렬로 처리될 때 효율적인 구간과, 동기적으로 처리해야 하는 구분을 나눌 것

프로그램에서 독립적으로 처리될 수 있는 단위를 찾고, 
Baseline : 시간 숫자 하나가 아니라 입력, 정확성, 측정 범위와 반복 규칙을 고정한 비교 설계
전송 고정비 : 데이터를보낼때 데이터의크기(용량)와 상관없이'무조건기본적으로들어가는시간이나비용

#### Host와 Device
Host : CPU. 다음 역할들을 수행
- 프로그램 시작
- 데이터 준비
- GPU 메모리 할당 요청
- Kernel 실행 명령
- 결과 확인, 저장
Device : GPU. 다음 역할들을 수행
- 대량 Thread 실행
- Kernel 계산 수행
- Device 메모리 사용
- 병렬연산결과 생성
- 동기화 필요

CPU와 GPU는 메모리를 따로 쓰기 때문에 CPU에서 GPU로 데이터가 이동해야 하고, 다음과 같은 비용이 소모됨
- CPU RAM -> GPU Memory
- GPU Memory -> CPU RAM
- 전송 자체도 시간 소요
- 가능하면 불필요한 전송 줄이기

GPU -> GPU는 이동 비용을 신경쓸 필요 없음.

소규모는 CPU가 빠르고, 대규모는 GPU가 빠르다 (보통). 왜?
재료 손질은 GPU가 빠를 수 있음. 똑같은 일을 반복하니까
근데 재료를 가져오는 시간은? GPU와 상관이 없음 -> 어쩔 수 없는 고정비
어느게 빠른지 갈라지는 부분 (예)1000명) 이 경계를 크로스 오버라고 부름. CPU와 GPU의 속도가 비슷한 부분
소규모 작업의 경우 GPU의 특성(단순한 작업을 빠르게) 을 누리는 것보다 준비하는 비용이 더 클 수 있음.

최적화 시
어떤 걸 최적화할 지, 최적화 되었는 지 판단하기 위해 시간을 어떻게 측정할 지, 판단 지표는 어떤 걸로 정할지를 결정해야 함

병렬성에는 독립성이 제일 중요함.
병렬성은 서로 기다리지 않고 진행할 수 있는 일이 얼마나 있는 지를 뜻 함. 스레드 수를 뜻하는 것이 아님.
데이터 병렬성 : 동일한 행동을 서로 다른 데이터에 적용
작업 병렬성 : 서로 다른 종류의 일을 동시에 처리
직렬 구간 : 앞 작업이 끝나야만 일을 시작할 수 있는 '병렬화 불가능한 구간'



독립적인것은 뭘까?

독립 : Decode, Resize
Edge의 경우 의존과 독립성을 모두 가지고 있음
얘는 무조건 독립이야. 라고 판단하기가 어려움. 변수가 많기에. 그래서 설계가 어려운 것

코랩 켜서 파이썬 3, T4 GPU

직렬 경로 : 줄일 수 없음
병렬 경로 : 줄일 수 있음

GPU 작업 시 가장 긴 작업시간을 총 시간이라고 함
그래서 자원을 늘렸을 때 동시검토를 진행 해야 함 직렬 경로, 병렬경로, 통신-동기화 비용을
GPU 가속은 연산, 이동, 제어의 비율로 결정됨.
연산량 뿐만 아니라 연산 데이터, 데이터 이동, 제어 흐름 균일하게 보아야 함
계산 집약형 : 데이터 이동량에 비해 연산이 많은 구조. GPU 작업이 유리
메모리 집약 : 연산보다 대역폭이 병목인 구조. GPU 사용 시 오히려 느릴 수 있음. 준비 작업이 더 오래 걸리는 작업

![[Pasted image 20260919151446.png|717]]
비교 시 이동량 대비 데이터가 많은 지, 데이터 재사용을 많이 하는 지, 이런 걸 고려 해야 함
즉, 여러가지 지표를 비교해서 순위를 매겨야 함.
GPU에 따라 이런 지표들이 달라지기도 하고 무조건 정답은 아니지만 이런 걸 고려해야 함.

암달의 법칙 : 줄일 수 있는 구간만 줄일 수 있다. 직렬 구간이 실행 시간을 정한다
직렬 구간 : 네트워크 , 하드웨어 성능 등. 줄일 수 있는 가능성이 적음

생각보다 로직 자체가 잘못되는 경우도 있음. 이 경우 직렬도 실행 시간을 줄일 수 있는 여지가 있다는 것.

strong : 같은 작업이 시간이 얼마나 줄었는지
weak : 작업량을 늘려도 시간이 얼마나 유지되는 지
