메모리 page가 2종류 있음
Anonymous page : malloc 같은 거 쓸 때, nmap 같은 거 쓸 때. 유사 시 복구 불가. 파일과 연결이 하나도 안 됨. 일반적으로 못 살림.
file backed page : File 페이지, nmap 쓸 때 shared 집어 넣었을 때. 다시 open 하면 됨. 기본적으로 file로 저장됨 (disk에). 죽어도 사릴 ㅜㅅ 있음
이 중 swap 할 놈은 Anoymous. 못살릴 놈을 swap
요즘 메모리가 커져서 swap은 잘 안 쓰지만
Anonymous page의 백업용으로 swap을 쓰고 anoymous page를 swap 영역에 넣음
