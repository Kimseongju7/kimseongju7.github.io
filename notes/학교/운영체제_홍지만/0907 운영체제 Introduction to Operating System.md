### 교수님 강의 요약
1. 추상화와 가상화의 차이 : 하드웨어 자원을 추상화(객체화 -> Class 화 -> 구조체화). CPU를 추상화한 대표적인 구조체 proc(Unix, BSD, XV6 등. task_sturct (리눅스) 등  
2. CPU 가상화 : CPU가 1개 임에도 불구하고, 모든 프로세스들은 각자 CPU를 별도로 갖는 환상을 제공  
3. 이러한 가상화가 가능하게 하는 것이 switch() 임.  IO 인터럽트/타이머 인터럽트 -> schedule() -> switch()  
4. 교재에서 읽어야 할 부분 : 번역 오픈소스 기준. 제 2장. 운영체제 개요. 향후 교재에서 읽어야 할 부분에 있는 볼드체 명사들은 중간/기말시험 () 넣기 문제로 출제 가능.
