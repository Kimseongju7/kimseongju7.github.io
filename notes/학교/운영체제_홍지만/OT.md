### OT 내용
OS = Operating System = 운영체제 = 자원관리자
놈 자 자 = 소프트웨어 
Device Driver = 장치 구동 자

컴퓨터의 3대 구성 요소 : CPU, MEM, DISK
운영체제가 관리 하는 자원, 하드웨어

그럼 어떻게?
애니악 처럼 하드웨어를 선으로 연결하면서 자원을 관리할 수도 있겠지만, 너무 느림
=> 추상화 시키자

추상화 : 소프트웨어가 하드웨어를 다루려면 하드웨어 자체를 Object로 만들어야 함. 결국 Class로 만들어야 함
CPU는 integer로 나타낼 수는 없으니. 복잡해서 하나의 자료형을 만들 수는 없으니.
결국 Struct. 구조체로 만드는 것.

옛날 CPU를 추상화한 struct의 이름이 proc 이었음 (Unix), Linux는 task_struct
memory는 mm, Disk는 fs
이런 struct, 추상화한 소프트웨어를 조작하려면 함수가 있어야 함. 그게 시스템 콜임.
시스템 콜이 커널함수를 부름

교재 이름이 Operating System Three Easy Piece : OSTEP 이라 하는데
CPU를 추상화한 이야기, Memory를 추상화한 이야기, Disk를 추상화한 이야기
추상화는 그냥 구조체라 생각하면 됨. 데이터 타입이 복잡한 Object
운영체제는 지금도 코드가 많아서 생성자, 소멸자 같은 c++ class 코드 사용 못 함

xv6는 7개의 주요 멤버변수가 있음. 시중 운영체제는 400개가 넘음

교재 모든 챕터마다 Interlude가 있음. 챕터 시작 전 이야기. 무시해도 됨.
