### switch
switch 함수 사용 시 3가지가 바뀜
1. 레지스터 문맥
2. 메모리 문맥 : 가상메모리 계산법? 그게 변경됨.
3. 시스템 문맥
그렇지만 switch는 굉장히 짧은 오버헤드. 하나 당 몇 마이크로 세컨드
많이 하면 당연히 오버 헤드가 커지겠지만 생각보다 적고,
많이 하면 동시에 돌아가는 것 처럼 보이게 떄문에 현대 os에서는 switching을 자주 사용
switch()는 schedule() 함수가 호출하고
schedule()은 다음 실행될 task_struct, proc_structure, **PCB**(Process Control Block) 반환

가상화 : 자원이 여러 개있는 것처럼 만들었다. 각자의 cpu, memory를 가지고 있는 것 처럼
병행성 : 동시에 돌아가는 것처럼 남기다
영속성 : 전기가 날아가도 문제가 없게 하다.

대기업은 보안 안 함. 보안은 무조건 뚫림. 그러면 팀이 날아감

### PCB 구성요소
우선순위 = proiority = nice (linux)
메모리 포인터 : 가상메모리 mm*
프로그램 카운터 : cpu 차지 시간
문맥 데이터 = 레지스터 문맥 = \*thread_struct (linux)
어카운팅 정보 : 슈퍼컴 사용 시 계정 생성해서 사용하는데 cpu 사용 시간 만큼 비용 부여
